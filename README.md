# NexusAdmin - Full-Stack MERN Admin Dashboard

An enterprise-grade, fully responsive MERN stack admin panel built with React, Node.js, Express, MongoDB, and Tailwind CSS.

## 🚀 Features
- **Authentication:** JWT-based access with Role-Based Control.
- **Analytics:** Dynamic area charts using Recharts.
- **CRUD Operations:** Real-time search, sorting, and pagination.
- **Export Capabilities:** Export analytics data to CSV.

## 🛠 Tech Stack
- **Frontend:** React.js (Vite), Tailwind CSS, Recharts.
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT.
